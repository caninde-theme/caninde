# Canindé for VS Code

A dark theme inspired by the **Arara-Canindé** (*Ara ararauna*), the blue-and-yellow macaw: blue on the back, gold on the chest, a deep beak-black canvas.
Um tema escuro inspirado na **Arara-Canindé**: azul no dorso, ouro no peito e um fundo preto-bico profundo.

## Install / Instalação

1. Open the Extensions view (`Ctrl+Shift+X` / `Cmd+Shift+X`).
2. Search for **Canindé**.
3. Click **Install**, then pick **Canindé** under *Preferences: Color Theme*.

## Highlights

- Keywords in feather **blue**, functions in **gold**, strings in crown **green**, numbers in neck **orange**.
- Every text color is checked for WCAG AA contrast on each build (7:1 for default text).
- Semantic highlighting enabled.
- Generated from shared design tokens, so the terminal, other editors and apps stay consistent with this one.
